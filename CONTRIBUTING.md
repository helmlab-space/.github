# Contributing

Thank you for helping. This applies to every repository of the [helmlab-space](https://github.com/helmlab-space) organization that has no CONTRIBUTING file of its own.

- Bug reports: name the package and its version, give the exact input, and say which output you expected and which you got.
- Pull requests: one topic per pull request; run the repository's tests before you open it.
- Frozen definitions: the outputs of Helmlab 2026 do not change. A change that would alter them belongs to a later definition.
- Numbers: give the source of every number you add.

## AI tools

You may use AI tools when contributing. You are responsible for everything you submit: read and understand every line, run the tests, and check every number against its source.
